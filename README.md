# Generative AI Projects

This repository showcases various implementations of Generative AI techniques using frameworks like Langchain and Hugging Face. The project includes features like text summarization, SQL chat, document QA, and more.

## Features
- **Text Summarization**: Implemented using Hugging Face models integrated with Langchain.
- **SQL Chat and Search Engine**: Allows users to interact with SQL databases through natural language queries.
- **RAG Document QA**: Utilizes Retrieval-Augmented Generation techniques for answering questions from documents.
- **Conversational Q&A Chatbots**: Built specific chatbots for websites leveraging Groq and Ollama.
- **Managing Message History**: Keeps track of chat histories for better user experience.
- **API Server**: Set up using Langchain to serve various functionalities.
- **Data Ingestion and Splitting**: Handles data preparation for machine learning tasks.
