# Generative AI 🌟

Welcome to the Generative AI Project repository! This project serves as a comprehensive resource for users looking to learn about the Generative AI landscape and the Langchain ecosystem. It provides a structured workflow that guides users from the basics to advanced concepts, enabling them to create their own AI projects.

The repository covers essential steps such as data ingestion, data splitting, embedding, and querying, utilizing various techniques and models, including Hugging Face, OpenAI, Ollama, Groq, and more. By experimenting with different methodologies, users will gain a robust understanding of how to implement AI solutions effectively.

## Features 🚀

- **Text Summarization** ✍️: 
  - Leverage Hugging Face models to provide summarization capabilities. This feature condenses lengthy texts into shorter summaries while retaining key information.
  
- **SQL Chat and Search Engine** 🔍: 
  - Users can interact with SQL databases through natural language queries, allowing for intuitive data retrieval and manipulation without needing to write SQL code.
  
- **RAG Document QA** 📄: 
  - Implements Retrieval-Augmented Generation techniques to enable question-answering from documents, combining information retrieval with generative models for precise answers.
  
- **Conversational Q&A Chatbots** 💬: 
  - Build tailored chatbots for specific websites using Groq and Ollama, enabling users to get instant responses to their queries in a conversational format.
  
- **Managing Message History** 🗂️: 
  - Features functionality to track and manage chat histories, improving user experience by allowing users to revisit previous conversations.
  
- **API Server** ⚙️: 
  - A robust API server created with Langchain to expose various functionalities as endpoints, making integration with other applications seamless.
  
- **Data Ingestion and Splitting** 📊: 
  - Handles the preparation of data for machine learning tasks, including data ingestion from various sources and splitting it into training, validation, and test sets.
